# Oracle Migration Demo

This repository is a demonstration project for an Oracle 19c migration using Oracle Zero Downtime Migration (ZDM).

Source:
On-Premises Oracle Database 19c

Target:
Oracle Database@Azure

Migration Method:
ZDM Online Physical Migration

The following artifacts should be generated:

1. Pre-Migration Check Script
2. ZDM Physical Migration Response File
3. ZDM Evaluation Script
4. ZDM Migration Execution Script
5. Post-Migration Validation SQL
6. Post-Migration Validation Shell Script
7. Migration Runbook

Do not include passwords, tokens, or private keys directly in source code.

Scripts should use variables or environment variables for environment-specific values.
