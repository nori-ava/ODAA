# Target Environment

- Target Platform: Oracle Database@Azure
- Oracle Database Version: Oracle Database 19c
- Edition: Enterprise Edition
- Target Architecture: Single Instance
- Region: Japan East
- TDE: Enabled
- Backup: Oracle managed backup
- Connectivity: Azure VNet connectivity
- High Availability: Required
- Disaster Recovery: To be designed

## Migration Requirements

- Oracle native migration tools should be prioritized.
- Downtime must be within 2 hours.
- Migration rehearsal is mandatory.
- Rollback procedure must be defined.
- Post migration validation must be completed before service restart.
